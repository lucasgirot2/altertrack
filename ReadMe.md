# 🎯 AlterTrack

Application web de recherche d'alternance — agrège des offres en temps réel et permet de suivre ses candidatures.

## Demo
👉 [altertrack-rouge.vercel.app](https://altertrack-rouge.vercel.app)

## Fonctionnalités
- Offres d'alternance en temps réel via l'API Adzuna
- Filtrage par zone géographique
- Suivi des candidatures
- Intégration directe avec MatchLetter pour analyser une offre avec l'IA

## Stack technique
- HTML/CSS/JS vanilla
- Node.js (fonctions serverless Vercel)
- API Adzuna
- API Claude (Anthropic) via MatchLetter
